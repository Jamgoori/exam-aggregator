# 통합본 PDF를 과목별로 분리할 때

한 PDF에 여러 과목이 묶여 있는 시험(교시별 통합본, 직렬별 통합본)은 `bulk-upload`가
집어갈 수 있게 "과목명.pdf"로 먼저 잘라야 한다. 조판에 따라 쓰는 스크립트가 다르다.

| 조판 | 스크립트 |
|---|---|
| 표지 1쪽에 목차(`【형 사 법】 (공통) ······ 1`)가 있는 통합본 — 경찰 간부후보 2018~2026 | `npm run split-by-toc -- --dir "src/testpaper/2026 경찰 간부후보" --out uploads/incoming/2026 [--dry]` |
| 페이지 머리글에 과목명이 매 쪽 박힌 통합본 — 국회직 | `npm run split-by-subject-header` |
| 과목 첫 쪽에만 `【 소방학개론 】` 머리글이 있는 통합본 — 소방 공채·경채 2018~2026 | `npm run split-fire -- --dir "TEST/소방 공채/2026" --out uploads/incoming/소방-공채-2026 [--dry]` |
| 위 셋 다 아님(사람이 페이지 경계를 눈으로 정해야 함) | `npm run split-combined-pdf -- --detect` 후 `--boundaries` 지정 |

## split-fire 주의사항

- 경계를 **본문 머리글**과 **표지 쪽범위("제1과목 소방학개론 1~6")** 두 경로로 잡고
  서로 대조한다. 어긋나면 그 파일은 자르지 않는다.
- 2026 공채 문제지는 머리글이 없고 표지 텍스트도 순서가 꼬여 나온다(`제 과목
  소방학개론1 1~6`). 표지 쪽범위 + 본문 1쪽 오프셋으로만 자르고 경고를 낸다 —
  이 경고가 뜬 파일은 결과를 사람이 확인할 것.
- 자른 뒤에는 **과목별 PDF의 마지막 문항 번호와 정답표 문항 수를 대조**하는 게
  반쪽 분리를 잡는 가장 확실한 게이트다(2018~2026 132장 전량 이 방법으로 검증).
- 소방은 같은 해 공채·경채가 국어·영어·소방학개론을 **같은 문제**로 쓰지만
  소방관계법규는 다르다. 두 벌 다 올리고 경채는 `--track 경채`를 붙인다.

## split-by-toc 주의사항

- **반드시 `--dry`로 먼저 확인.** 경고가 하나라도 있으면 그 파일은 자동으로
  건너뛴다(반쪽짜리 분리본을 만들지 않기 위한 안전장치).
- 과목 시작 페이지는 **본문 머리글(`- 1 - 2 교 시 정 보 보 호 론 …`)을 1순위**,
  목차 쪽번호를 2순위로 쓴다. 목차 숫자는 PDF 텍스트 추출이 흘리는 경우가 있다
  (실측: 2023 경찰간부 사이버 통합본에서 `20`이 `0`으로 추출됨).
- 표지에도 `- 1 -` 쪽번호가 찍힌 연도가 있어 쪽번호→PDF 페이지 대응표는 2쪽부터
  만든다.
- 같은 배치에서 같은 과목명이 두 번 나오면(여러 직렬 통합본이 공통과목을 중복
  수록) 뒤엣것은 건너뛴다. 정말 같은 문제인지는 사람이 한 번 확인할 것.
- 주관식 시험지(경찰 간부후보 3·4교시, 2022년 이전)는 애초에 대상에서 빼고
  돌린다 — 객관식 CBT/문항 크롭 대상이 아니다.

## 과목명 매핑

잘린 파일명이 곧 과목명이 되고 `bulk-upload.mjs`의 `SUBJECT_ALIASES`를 탄다.
문제지 표기와 DB `subjects.name`이 다르면(행정학→행정학개론, 행정법→행정법총론)
거기에 별칭을 추가할 것. 가운뎃점이 낀 과목명(`시스템․네트워크보안`)은 파일명을
DB 표기(`시스템네트워크보안`)로 바꿔 저장하면 된다.

별칭이 정하는 건 **어느 `subjects` 행에 붙일지**뿐이다. 시행처가 그 과목을 다른
이름으로 부르면(군무원은 "행정법"·"행정학") 문제지는 같은 과목 행에 모으고,
**화면 이름만 `packages/core/src/subject-label.ts`에서 되돌린다.** 새 시행처를
등록하다 표기가 어긋나면 과목 행을 새로 만들지 말고 거기에 한 줄 추가할 것 —
자세한 이유는 `docs/agents/subject-names.md`.
