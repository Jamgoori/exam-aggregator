# 시행처마다 다른 과목명

## 무슨 일이 있었나 (2026-08)

군무원 문제지 26장(9급·7급, 2020~2026)이 "2026 군무원 9급 **행정법총론**"으로
올라가 있었다. 군무원 문제지 표지·공고의 과목명은 **행정법**이고, 업로드한 원본
파일명도 `행정법.pdf`였다. 행정학도 같다(`행정학.pdf` → 행정학개론).

원인은 `bulk-upload.mjs`의 `SUBJECT_ALIASES`다. `행정법 → 행정법총론` 별칭이
시행처를 안 보고 걸려서, 파일명의 원 표기가 국가직 표기로 덮여 저장됐다.

## 왜 과목 행을 안 쪼갰나

`subjects` 에 `행정법` 행을 새로 만들어 군무원 문제지를 옮기는 방법도 있고, 실제로
국가직 7급 전용 과목(`경제학`/`경제학개론`)이나 군무원 사서직(`자료조직론`/
`자료조직개론`)은 그렇게 별도 행으로 등록돼 있다. 이번엔 그렇게 하지 않았다.

- **개념 사전이 과목 단위다.** `concepts` 44개와 그 별칭이 행정법총론·행정학개론에
  달려 있고, 대상 26장에 이미 해설 300건·개념 연결 66건이 붙어 있다. 행을 쪼개면
  사전을 복제하고 붙어 있는 `concept_id` 를 새 id 로 옮겨야 하는데, **개념 id
  재발급은 금지선**이다(`concept-dictionary.md`). 사전이 둘로 갈리면 이후 해설
  배치도 두 벌을 따로 관리해야 한다.
- **내용이 같은 과목이다.** 한 행으로 두면 군무원 수험생이 국가직·지방직 행정법총론
  문제지까지 같은 과목으로 이어서 풀 수 있다. 쪼개면 풀 수 있는 문제 모수가 13장으로
  줄어든다.
- 검색은 상위 개념인 "행정법"이 "행정법총론"에 접두 매칭되므로, 한 행이든 두 행이든
  "행정법"으로 검색하면 총론까지 함께 걸린다(`packages/core/src/search.ts`).

## 규칙

**`subjects.name` 은 국가직·지방직 표기를 정본으로 둔다. 다르게 부르는 시행처는
`packages/core/src/subject-label.ts` 에 한 줄 추가해 표시 단계에서 되돌린다.**

```ts
const SUBJECT_NAME_BY_EXAM_TYPE = {
  군무원: { 행정법총론: "행정법", 행정학개론: "행정학" },
};
```

- `getSubjectDisplayName(과목명, 시행처명)` — 그 문제지의 과목 이름을 보여줄 때.
- `applyExamTypeSubjectName(제목)` — 제목만 들고 있는 자리. 제목의 둘째 토큰이 늘
  시행처라 인자를 더 받지 않는다. `getPaperDisplayTitle` 이 안에서 이미 부른다.

## 금지선

- **`exam_papers.title` 을 UPDATE 로 고치지 말 것.** 업로드 시점의 기록이고,
  화면 이름은 표시 층에서 정한다. 저장값을 고치면 두 규칙이 생겨 서로 어긋난다.
- **표시 규칙을 화면 한 곳에만 넣지 말 것.** 카드·문제지 상세·CBT·해설·OG 이미지·
  RSS·오답노트·앱까지 같은 제목이 실린다. 한 군데라도 빠지면 같은 문제지가 화면마다
  다른 과목으로 보인다. 그래서 규칙을 `@gongmoa/core` 한 곳에 두고 제목 함수가
  자동으로 타게 했다.
- **여러 시행처가 섞이는 화면에는 걸지 말 것.** 과목 페이지(`/subjects/[slug]`),
  과목 오답노트 제목, 즐겨찾기 과목 목록은 DB 이름이 정본이다. 그래야 "행정법"으로
  들어와 "행정법총론 기출문제"까지 이어서 보는 길이 남는다.
- **표기가 다르다고 과목 행을 새로 만들지 말 것** — 위의 이유. 정말 다른 과목이라
  쪼개야 한다면(시험 범위 자체가 다른 경우) 개념 사전 이관 계획을 먼저 세울 것.

## 확인 방법

```
npm test --workspace @gongmoa/core                # 표시 규칙 단위 테스트
cd apps/web && npm run check-subject-names        # 빠른 점검 (파일명 대조, 몇 초)
cd apps/web && npm run check-subject-names -- --pdf   # 정밀 점검 (표본 PDF 대조, 10분쯤)
```

**빠른 점검**은 `exam_papers.file_name`(업로드 원본 파일명)에서 과목명을 되뽑아
`subjects.name` 과 다른 조합을 시행처별로 센다. 이 사고는 여기 그대로 드러났다
(군무원 행정법 13 · 행정학 13). 다만 두 가지를 못 본다.

- **파일명은 축약형인 경우가 많다** — `형소법`, `네트워크보안`. 다르다고 다 문제가
  아니다.
- **통합본에서 잘라 올린 문제지는 파일명이 과목명이 아니다** — `1교시 1책형`,
  `2015 경찰 공채 3차.pdf p6`. 법원직·경찰 상당수가 여기라 아예 안 보인다.

그래서 **정밀 점검(`--pdf`)이 정본**이다. (시행처, 급수, 과목) 조합마다 연도
양끝·가운데를 표본으로 내려받아 **문제지에 실제로 인쇄된 과목명**과 대조한다.
급수까지 나누는 이유는 같은 시행처가 급수마다 다르게 부르기 때문이고(국가직 9급
행정법총론 ↔ 7급 행정법), 연도를 여럿 보는 이유는 과목명이 개편되기 때문이다
(국회직 8급 언어논리). `--type 군무원` 으로 한 시행처만 볼 수 있다.

판정이 `미검출`·`텍스트없음` 인 표본은 스캔본이라 텍스트 층이 없거나 표지에 과목명이
없는 문제지다. 버그가 아니라 **이 방법으로 판정 못 한 것**이니 사람이 직접 열어 볼 것.
